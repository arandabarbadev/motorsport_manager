# Quickstart 016

1. `npm run build` — verde.
2. `npm run harness` — aparece `Difficulty check: ... OK` junto a los checks existentes.
3. `vite preview` en 4173 + Chrome CDP 9222 → `node %TEMP%\mm-v016.js`.
4. A mano, si se quiere: Partidas → ranura vacía → elegir dificultad → Crear → mirar el dinero y la pestaña Patrocinadores.

**Señales de éxito**: la tarjeta vacía ofrece Fácil/Normal/Difícil con una línea que resume cada una; crear en Fácil arranca con 350 M€ y patrocinios hasta 5,0 M€; las partidas viejas dicen "Difícil" y no se les mueve un euro.
